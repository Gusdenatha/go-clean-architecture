# Go REST API Template

REST API template using Golang and Gin.

## Requirements

- [Go](https://go.dev/dl/)
- [Git](https://git-scm.com/)

## Setup

**1. Install dependencies**

```bash
go mod download
```

**3. Run application**

```bash
go run ./cmd/server
```

## Test API

```http
GET http://localhost:8080/health
```
